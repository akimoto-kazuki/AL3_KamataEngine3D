# 11月分進捗
## 操作方法
ADで横移動SPACEでジャンプ  
左クリックで弾を発射  
マウスで照準オブジェクトの移動
## 今月の成果一覧
- 照準オブジェクトをマウスで動かす
  - 10月で出来なかった、マウスで照準オブジェクトの移動ができた。  
- 左クリックで弾を発射  
  - 左クリックで弾を発射を追加した。  
- プレイヤーの弾の連射とクールタイムの追加と弾の消滅  
  - 弾を連射できるようにした。  
  - 弾の連射で弾の間隔空いていなかったから、クールタイムを追加して、間隔をあけた。  
  - 見た目ではよくわからないが弾が時間制限で消えるようにした。  
- 敵とプレイヤーの弾の当たり判定  
  - 敵と弾が当たった時に敵とプレイヤーの弾が消えるようになった。  
- 照準オブジェクトに向かって弾を飛ぶようにした。  
  - マウスで照準オブジェクトを動かした後に左クリックで弾を飛ばすと照準オブジェクトに向かって弾が進んでいくようにした。  
- 弾の向きを飛んでいく方向に変えた  
  - 弾を飛ばすとき、真っ直ぐに飛んでいくものを進行方向に向いて飛ぶようになった。  
## その他  
12月では、モデルの差し替え、敵を倒したときの演出の追加をメインでやり、時間があり次第出てくる敵の種類を追加することをやる。

# 10月分進捗
## 操作方法
ADで横移動Wでジャンプ  
上下左右で照準オブジェクトの移動  
## 今月の成果一覧  
- 照準オブジェクトの描画と上下左右の移動  
  - 照準オブジェクトを追加した。  
  - 照準オブジェクトを上下左右で移動できるようにした。  
## その他  
照準オブジェクトをマウスで操作できるようにしたかったが、照準オブジェクトを描画することに時間をかけてしまった。  
11月では照準オブジェクトをマウスで動かせるようにする、弾を発射できるようにするを目標にやっていく。
