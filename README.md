# 11月分進捗
## 操作方法
ADで横移動Wでジャンプ  
SPACEで弾を発射  
マウスで照準オブジェクトの移動
## 今月の成果一覧
- 照準オブジェクトをマウスで動かす
  - 10月で出来なかった、マウスで照準オブジェクトの移動ができた。  
- SPACEで弾を発射  
  - SPACEで弾を発射を追加した。  
- プレイヤーの弾の連射とクールタイムの追加と弾の消滅  
  - 弾を連射できるようにした。  
  - 弾の連射で弾の間隔空いていなかったから、クールタイムを追加して、間隔をあけた。  
  - 見た目ではよくわからないが弾が時間制限で消えるようにした。  
- 敵とプレイヤーの弾の当たり判定  
  - 敵と弾が当たった時に敵とプレイヤーの弾が消えるようになった。  
## その他  
弾を発射できるようになったが、弾がプレイヤーから照準オブジェクトに進んでいくように出来なかった。  
12月では弾が照準オブジェクトに向かって飛んでいくこと、出てくる敵の種類を追加する。

# 10月分進捗
## 操作方法
ADで横移動Wでジャンプ  
上下左右で照準オブジェクトの移動
## 今月の成果一覧
- 照準オブジェクトの描画と上下左右の移動
  - 照準オブジェクトを追加した。
  - 照準オブジェクトを上下左右で移動できるようにした。
## その他
照準オブジェクトをマウスで操作できるようにしたかったが、照準オブジェクトを描画することに時間をかけてしまった。  
11月では照準オブジェクトをマウスで動かせるようにする、弾を発射できるようにするを目標にやっていく。
